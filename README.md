# Relaxing Study Space 🌿

A beautiful, calming website designed for focused studying and working. Features automatic relaxing music playback, a Pomodoro timer, and ambient sound options.

## Features

- 🎵 **Automatic Music Playback** - Relaxing background music starts automatically when you open the site
- ⏱️ **Focus Timer** - Built-in Pomodoro timer with preset options (25, 45, 60 minutes)
- 🌊 **Ambient Sounds** - Choose from rain, forest, ocean, or fireplace sounds
- 🎨 **Beautiful Design** - Calming gradient backgrounds and smooth animations
- 🔊 **Volume Control** - Adjust music volume to your preference
- 📱 **Responsive** - Works perfectly on desktop, tablet, and mobile devices

## Usage

1. Open `index.html` in your web browser
2. The music will start playing automatically (if your browser allows autoplay)
3. Use the play/pause button to control music playback
4. Adjust volume with the slider
5. Set a focus timer for your study session
6. Add ambient sounds for extra relaxation

## Customizing Music

To use your own music file:

1. Place your music file (MP3 format recommended) in the same folder
2. Update the `<source>` tag in `index.html`:
   ```html
   <source src="your-music-file.mp3" type="audio/mpeg">
   ```

## Browser Compatibility

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Autoplay may be blocked in some browsers - simply click the play button if needed
- For best experience, use a recent browser version

## Notes

- The music source uses a royalty-free example track. You can replace it with your own music.
- Ambient sounds are placeholders - you can add actual sound files for a complete experience.
- The timer will alert you when time is up.

Enjoy your focused study session! ✨
